# lppw-world

Headless procedural world generation and spatial simulation model.

## Features

- **Topography presets**: Archipelago, Alpine Highlands, Canyonlands, and Alien Crags.
- **Biomes**: Classification based on height, slope, moisture, and settlement road/plaza overlays.
- **Settlement & Landmark spatial placement**: Pure-mathematics placement and plateau blending without rendering dependencies.
- **Fast toroidal caching**: O(1) cell lookup for consistent generation across chunks.
